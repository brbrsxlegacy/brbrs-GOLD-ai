# brbrs Gold AI

Siyah-altın klas Gemini chat.

## Render ayarları

Build Command:
npm install

Start Command:
npm start

Environment Variables:
GEMINI_API_KEY = kendi_api_keyin
GEMINI_MODEL = gemini-2.0-flash

Not: Bu ad bazlı localStorage kullanır. Gerçek şifreli üyelik değil; aynı tarayıcıda adlara göre ayrı kayıt tutar.
